# Leveraged Buyout (LBO) Financial Model

This repository contains a simplified Leveraged Buyout (LBO) model built in Excel based on a financial modeling exercise from Wall Street Prep.

## Model Overview
The model evaluates the acquisition of a company using debt and equity financing.

### Key Components
- Sources & Uses of Funds
- Debt Schedule
- Cash Flow Projection
- Investor IRR Calculation
- Exit Analysis
